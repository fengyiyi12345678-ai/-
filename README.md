# 2024 五大联赛强队盘口输盘复盘 — 抓取与分析框架

> 研究主题：强队作为「流量品牌」，在热门开球时间 / 周末黄金档 / 当天比赛稀缺 / 流量集中时，
> 是否更容易因「盘口被市场买热抬深」而出现 **「赢球但输盘」/「热门强队输盘」** 现象。

本仓库 **不内置任何比赛数据**。它给出一套可在本地运行的端到端管线：
**抓取 → 清洗 → 标签化 → 输盘率计算 → 21 个 Sheet 的 Excel + 中文复盘报告 + 实盘跟踪表 + 资金测算**。

数据源以 `live.nowscore.com`（即时比分网）为主抓取目标，并预留了一个 CSV 兜底入口
（任何包含必要字段的来源都能接入，例如 football-data.co.uk 的 1X2 + 亚盘历史 CSV）。

---

## 0. 重要前置说明（请先读）

1. **盘口数据不能编造。** 报告所有结论的前提是「最终盘口 / 临场盘口」字段真实，
   缺失则该场必须打 `盘口缺失` 标签，从输盘率分母中剔除。请勿手填猜测值。
2. **2024 自然年跨两个赛季**（2023/24 后半段、2024/25 前半段），每条记录都会带 `season` 标签，
   总表与赛季对比表分开输出。
3. **样本 < 5 场必须标注「样本不足，不能过度推断」**，由 `aggregator.py` 自动注入提醒列。
4. **走水不计入分母**：有效输盘率 = (全输 + 0.5×半输) / (总盘口场次 − 走水场次)。
5. nowscore 是动态站点，**抓取脚本只是骨架**。第一次使用必须根据当前页面 DOM / 接口结构
   补全 `scraper/nowscore_client.py` 中标注 `# TODO: confirm selector / endpoint` 的位置。

## 2. 安装与运行

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 方式 A：先抓取 nowscore（需联网；首次跑请先补 selector）
python run.py scrape --start 2024-01-01 --end 2024-12-31 \
                     --leagues epl,laliga,bundesliga,seriea,ligue1

# 方式 B：从 CSV 兜底入口加载（推荐先用此方式跑通管线）
python run.py load-csv --path data/raw/2024_top5_combined.csv

# 生成 21 个 Sheet 的 Excel + 中文复盘报告
python run.py analyze --in data/raw/matches_2024.parquet \
                      --out data/output/2024_strong_team_handicap.xlsx \
                      --report data/output/2024_report.md
```

## 3. 输盘率口径

```
有效输盘率 = (全输 + 0.5 × 半输) / (总盘口场次 − 走水场次)
粗略输盘率 = (全输 + 半输)         / (总盘口场次 − 走水场次)
盈亏平衡线 = 54.05%   (对应水位 0.85，即 1/(1+0.85))

A 级：样本 ≥ 10 且 有效输盘率 ≥ 65%
B 级：样本 ≥ 10 且 60% ≤ 有效输盘率 < 65%
C 级：5 ≤ 样本 < 10 且 有效输盘率 ≥ 65%   （仅观察）
禁止：有效输盘率 < 54.05%
```

## 5. 已知限制

- nowscore 是动态站点，可能存在反爬。脚本未内置代理池，请遵守目标站 robots / TOS。
- 「亚盘初盘 / 即时盘」可能存在缺失或回写延迟，**最终输盘率以「最终盘」为准**。
- 「当天五大联赛总场次」依赖于抓取全量五大联赛日历，缺失则该场标签为 `缺失`。
- 模型只回测「反强队」一个方向；不是预测胜负的模型。
