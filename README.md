# 淘宝竞品评价分析工具（半自动版）

> **为什么不写全自动爬虫？** 淘宝有 sign 加密、滑块验证、IP 风控，
> 自写爬虫不仅违反《用户协议》还存在法律风险（参考 2023 年阿里诉某数据公司案）。
> 本工具采用 **手动采集 + 自动分析** 的方式：你花 1-2 小时复制 20 个商品的评价，
> 脚本帮你做情感分析、关键词提取，生成可直接用的竞品报告。

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 首次运行 `snownlp` 和 `jieba` 会自动下载词典，需要联网。

### 2. 生成 Excel 模板

```bash
python make_template.py
```

会生成 `competitor_template.xlsx`，包含：
- **竞品总表** — 填 20 个商品的标题/价格/月销量
- **P01_评价 ~ P20_评价** — 每个商品一张表，粘贴评价文字

### 3. 手动采集数据（核心步骤）

1. 打开淘宝，搜索你的关键词（如"无线耳机"）
2. 点击「销量」排序
3. 前 20 个商品依次填入 `竞品总表`：
   - 商品标题、店铺名、链接、价格、月销量、累计评价数、页面好评率
4. 打开每个商品详情页 → 评价区，按"中差评"标签切换，把评价文字复制到对应的 `Pxx_评价` 表
   - **B 列（评价内容）必填，其他列可选**
   - 每个商品建议至少采 20-50 条评价（好/中/差混合）
   - "评价类型"列留空即可，脚本会自动判断；想强制覆盖就填"好评/中评/差评"

> 💡 小技巧：用浏览器 F12 → Console 跑 `$$('.rate-content').map(e=>e.innerText).join('\n')`
> 可以一次性把当前页评价文字拷出来（需要先登录）。

### 4. 跑分析

```bash
python analyze.py
```

输出在 `report/` 目录：
- `summary.csv` — 20 个商品的销量 + 好/中/差评数 + 实测好评率
- `report.md` — 完整分析报告（含品类共性槽点、每个商品详评、行动建议）

## 输出示例

```
## 二、全市场差评关键词 TOP20
| 关键词 | 出现在几个商品 |
|---|---|
| 续航 | 14 |
| 异响 | 11 |
| 断连 | 9  |
| ...
```

→ 一眼看出整个品类的共性痛点，新品规避或营销时强调。

## 文件说明

| 文件 | 作用 |
|---|---|
| `make_template.py` | 生成 Excel 数据收集模板 |
| `analyze.py` | 跑情感分析 + 生成报告 |
| `requirements.txt` | Python 依赖 |
| `competitor_template.xlsx` | （运行后生成）数据收集模板 |
| `report/` | （运行后生成）分析结果 |

## 自定义

- 改阈值：`analyze.py` 顶部的 `POSITIVE_THRESHOLD` / `NEGATIVE_THRESHOLD`
- 改商品数：`make_template.py` 顶部的 `PRODUCT_COUNT`
- 加停用词：`analyze.py` 的 `STOPWORDS` 集合

## 合规说明

本工具**不包含任何自动抓取淘宝的代码**。
所有数据由使用者手工从公开页面采集，仅供个人调研学习，不得用于商业转售或大规模数据加工服务。
